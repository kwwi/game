## AnimalGameWeb 项目说明
游戏逻辑：
有如下棋盘游戏逻辑：
1、甲乙双方对弈
2、棋盘大小是7乘8
3、有角色（棋牌）：鲸2只、凤2只、龙2只、象2只、狮2只、虎2只、豹2只、财2只、狼2只、狗2只、猫2只、鼠4只，按照角色顺序前面的大后面的小，排在前面的角色能吃掉对弈方的较小角色（限制条件是两个角色相邻），但是鼠能吃鲸、凤、龙、象，形成循环。棋盘分为红色方和黑色方。角色只能一次移动一个位置，方向只能向上下左右。
4、初始化的时候角色随机分布在的棋盘上方格里，且排面向下，棋盘位置用r表示行从1开始计数，c表示列从1开始计数。其中[2,2]、[2,7]、[6,2]、[6,7]为特殊格子，初始的时候角色不能进入该格子，进入该格子后角色无敌，无法被攻击。
5、玩法：
a.甲方和乙方扔骰子，大的获得先手。假设甲方是先手，乙方是后手
b.初始阶段可以在棋盘上随机翻开一个棋牌，棋牌颜色确定了先手方操作的阵营，假设甲方翻到了红色棋牌，那么黑色棋牌属于乙方，反过来也一样。甲方回合结束。
c.乙方随机翻开棋牌，回合结束。
d.甲方回合：如果还有棋牌未翻面，可以选择翻棋牌，也可以操作红色棋盘防御（逃跑或者进入特殊格子）或者进攻。
c.乙方回合：如果还有棋牌未翻面，可以选择翻棋牌，也可以操作黑色棋盘防御（逃跑或者进入特殊格子）或者进攻。

本目录下是基于你设计的动物棋规则实现的 **前后端分离 Web 系统**：

- `backend`：Java + Spring Boot，负责对局管理和完整游戏规则逻辑。
- `frontend`：静态 Web 页面（HTML + 原生 JS），负责渲染棋盘和处理用户操作，通过 HTTP 调用后端接口。

### 前端界面说明（2026-03 更新）

- **页面背景**：整体为白色，文案为深色，便于阅读。
- **棋盘区域**：棋盘置于浅灰色底板（`.board-frame`，约 `#e8eaed`）内，格子为更浅的灰色系，与页面白底区分。
- **布局与自适应**：采用上下结构——上方为操作区（用户名、房间、状态等），下方主区域（`.board-stage`）用弹性布局将棋盘**水平垂直居中**，作为视觉中心。
- **棋盘缩放**：根据浏览器窗口与主区域可用空间，动态计算每格大小（`main.js` 中 `layoutBoardGrid`），窗口缩放或区域尺寸变化时会重新布局；棋子字号随格子大小略作缩放。
- **被吃子展示**：红方/黑方被吃列表放在棋盘底板下方，随棋盘同组居中。

## 后端服务启动方式（Spring Boot）

1. 打开终端，进入后端目录：

```bash
cd AnimalGameWeb/backend
```

2. 使用 Gradle 启动 Spring Boot 应用（第一次运行会自动下载依赖）：

```bash
./gradlew bootRun
```

3. 启动成功后，后端服务运行在：

```text
http://localhost:8080
```

主要接口（供前端调用）：

- `POST /api/games`：新建一盘对局，返回 `gameId` 和初始 `GameState`
- `GET /api/games/{id}`：获取当前对局状态
- `POST /api/games/{id}/flip`：随机翻一张未翻面的棋子
- `POST /api/games/{id}/move`：提交一步走子（由后端判定是否合法并更新状态）

## 前端页面启动方式（静态页面）

1. 打开另一个终端，进入前端目录：

```bash
cd AnimalGameWeb/frontend
```

2. 使用任意静态文件服务器启动前端（示例：使用 Python 自带的简单 HTTP 服务）：

```bash
python3 -m http.server 3000
```

3. 在浏览器中访问：

```text
http://localhost:3000/index.html
```

确保后端服务已在 `http://localhost:8080` 运行，此时你可以在页面上：

- 点击“新建对局”创建一盘新棋，并看到随机布局的 7×8 棋盘；
- 点击“随机翻牌”让后端随机翻开一个未翻面的棋子；
- 点击棋盘格：先选中当前阵营已翻开的棋子，再点目标格，前端会把走子请求发送给后端，由后端根据游戏规则处理并返回最新棋盘状态。
